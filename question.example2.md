### GitHub Foundations — Practice Test #2

**1.** A developer wants to contribute to a public repository but does not have permission to create branches in the original repository. What should they typically do?

A. Create a new organization
B. Fork the repository
C. Create a GitHub Discussion
D. Create a gist

**2.** You are working on a feature and want to keep your changes isolated from the default branch until they are ready. What should you create?

A. A gist
B. A fork
C. A branch
D. A milestone

A. `feature-login` is the base branch and `main` is the compare branch
B. `main` is the base branch and `feature-login` is the compare branch
C. Both branches are base branches
D. The base branch is always the branch with the newest commits

A. Issue template
B. Saved reply

D. Milestone

**5.** A team wants users to submit structured issue forms with specific fields rather than simply starting from a Markdown template. Which feature should they use?

A. Issue template

C. Pull request template
D. Discussion

A. A label
B. A keyword/reference that links the PR to the issue
C. A milestone
D. A project view

**7.** A developer wants to review exactly which lines have changed in a pull request. Which pull request tab provides this information?

A. Conversation
B. Commits
C. Checks
D. Files changed

A. A pull request can only contain one commit
B. The commits associated with the pull request represent changes between the compare and base branches

A. Labels
B. CODEOWNERS
C. Milestones

A. Subscribe to the thread
B. Fork the repository

**11.** A developer wants a simple way to share a small piece of code or text without creating a full repository. Which GitHub feature is intended for this?

A. Wiki

D. Project

A. Hosting static websites directly from a GitHub repository

A. GitHub Pages

A. Branch protection rules
